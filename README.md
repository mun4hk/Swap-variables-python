# Swap Variables (Python)

Simple Python exercise for beginners.  
The program asks the user to input two strings, prints them, then swaps the values of the variables.

## 🚀 How it works

1. The user enters two strings.
2. The program displays what was entered.
3. The variables swap their values using Python tuple assignment.
4. The result is printed back to the user.

## 🧠 Concepts practiced

- Input in Python
- Variables
- Basic string formatting (f-strings)
- Swapping variables: `a, b = b, a`
